VIDYAVARTA - RUN THE LIVE PROJECT (Version 1) - WINDOWS GUIDE
==========================================================

WHERE AM I? (do this check first - it matters)
----------------------------------------------
Open Command Prompt in the VidyaVarta folder you extracted. Your
prompt must END with  \VidyaVarta  and the folder must contain
package.json :

    PS C:\...\VidyaVarta>

If you see START-VIDYAVARTA.cmd here instead, you are inside an older
double-click package. This guide is for the source folder.

Good news about Node: the live project now runs on your existing
Node.js 24 (and on Node 22 LTS too). You do NOT need to install
another Node version.


STEP 1 - Install the project once (needs internet, ~2 minutes)
--------------------------------------------------------------
    npm ci --ignore-scripts
    npm rebuild better-sqlite3

Both must finish without red errors.


STEP 2 - Create your .env (your secrets - never shared with anyone)
-------------------------------------------------------------------
    copy .env.example .env
    notepad .env

Fill in at least, for a real email test (Gmail):

    SMTP_HOST=smtp.gmail.com
    SMTP_PORT=465
    SMTP_USER=yourgmailaddress@gmail.com
    SMTP_PASS=your-16-character-app-password
    SMTP_FROM=yourgmailaddress@gmail.com
    SMTP_ALLOWLIST=the-test-recipient@gmail.com

Notes:
  - SMTP_PASS is a Gmail APP password (Google Account > Security >
    2-Step Verification > App passwords), NOT your normal password.
  - SMTP_ALLOWLIST = the one consenting person who may receive test
    email. Your own address is fine.
  - There is no demo mode anywhere in Version 1. The app always
    starts live; these keys just decide what it can reach.

Optional (the brain): install Ollama from ollama.com/download, then
    ollama pull llama3.2:3b
That is all - VidyaVarta finds it automatically on 127.0.0.1:11434.

Optional (Google Classroom): see LIVE-SETUP.txt in this folder.


STEP 3 - Start live
-------------------
    npm run dev:live

Wait until you see a line like:
    [VidyaVarta] v1.0.0 | mode: LIVE | .env loaded (... keys)


STEP 4 - HOW TO KNOW YOU ARE LIVE (identity checks)
---------------------------------------------------
  1. Browser opens http://localhost:5173 - top of the page says
     LIVE-LOCAL.
  2. Open http://localhost:5173/api/health in a new tab. It must say
     "mode":"live" and "version":"1.0.0".
  3. First live start creates the operator account: the terminal
     prints a one-time admin password. Use it to sign in, then
     create your own account from the sign-in screen.
  4. The CONFIGURATION CHECKLIST on the Integrations page shows
     email/classroom/brain status from YOUR .env.

There are no fake accounts anywhere. The first start prints a one-time
admin password and saves a copy to  data\admin-password.txt .


IF YOU SEE THIS ERROR
---------------------
"Missing script: dev:live"   -> You are not inside the VidyaVarta
                                source folder (the one with package.json).
"Prebuild binary not found" / node-gyp compile errors ->
                                Make sure Step 1 ran INSIDE
                                the VidyaVarta folder with internet on.
Ollama card says not reachable -> Start the Ollama app once (llama
                                icon near the clock), then Recheck.
Anything else -> screenshot the terminal and ask.
